# وين صرفت — مختبر الرسائل العربية (تطبيق Android مستقل)

## الحالة
تطبيق اختبار منفصل تمامًا عن `app.wensarafet.tracker` الأصلي.

- **اسم APK:** Wen Sarafet Arabic SMS Lab
- **معرّف Android:** `app.wensarafet.smslab`؛ يثبت بجانب التطبيق الأصلي دون تحديثه.
- **الغرض:** تجربة التقاط رسائل مالية واردة *بعد تفعيل الإذن* وتحليل نصوصها بالعربية.
- **المحرك:** `ArabicSmsParserPilot` منفصل ومعزول عن المحرك الإنتاجي.
- **لا تتوفر فيه حسابات أو أرصدة أو سجل عمليات أو استيراد تلقائي**. كل نتيجة للمراجعة فقط.
- **لا صلاحية إنترنت، ولا قراءة الرسائل السابقة (`READ_SMS`)، ولا جهات اتصال**.
- لا نحتفظ برسائل كاملة أو اسم/رقم مرسل أو رمز تحقق. يسجل المختبر توقع الاتجاه والمبلغ والرصيد ومصدر الاختبار ووقت الالتقاط فقط.
- تُحفظ آخر 70 نتيجة مختصرة في بيانات تطبيق المختبر نفسه، ويمكن مسحها؛ لا تُشارك مع «وين صرفت».
- بعد التثبيت، افتح المختبر واسمح لـ`RECEIVE_SMS` من داخله لتجربة رسائل **جديدة**. إشعارات البنك/المحافظ تحتاج إذن وصول من Android وتفعيلًا منفصلًا داخل المختبر.
- مرسلو SMS غير المعروفين ليسوا مرفوضين إذا حمل النص مؤشرات حركة مالية وعملة، لتجنب افتراض اسم المرسل من رسالة واتساب. لا نقبل رموز OTP.
- إشعارات التطبيقات مقصورة على الحزم المستخدمة في النسخة الأصلية لبنك فلسطين وPalPay وجوال باي؛ قد تختلف حزمة التطبيق على جهاز آخر، وسنراجعها بدون قراءة جميع الإشعارات.
- النسخة لا تتصل بسيرفرات، ولا تُغيّر أو تخصم أي مبالغ.

## البناء والتوقيع
```bash
gradle :sms-lab:assembleRelease :sms-lab:lintRelease
```
GitHub Actions `.github/workflows/sms-lab-ci.yml` يرفع نسخة Release **غير موقعة** مع `apksigner.jar`؛ يجب توقيعها بمفتاح *تجريبي منفصل* خارج GitHub قبل إرسال APK قابل للتثبيت. لا يُستخدم توقيع «وين صرفت» الإنتاجي مطلقًا لمختبر الرسائل.

## حدود التجربة
نجاح GitHub Actions لا يثبت التقاط رسائل جهاز الصديق حتى يختبر أذونات SMS وظهور النتائج عليه. هذه النسخة ليست بديلًا للتطبيق المالي، ولا تعني الموافقة على دمج دعم العربية في التطبيق الأصلي. صاحب المشروع فقط يقرر الدمج بعد فحص البيانات والنتائج.
