# تسليم تحديث وين صرفت 1.8.1 — 30 أكتوبر 2026

## الحالة الصحيحة

الكود المتراكم في PR #24 على الفرع `feature/wen-batch21-reject-duplicate-zip-entries-20261030` جاهز كمرشح إصدار. المعرف `app.wensarafet.tracker`، ورقم البناء `17` (1.8.1)، وقاعدة البيانات v13. نجاح فحوصات GitHub **لا يعني** إجراء ترقية أو اختبار على جهاز فعلي.

**التوقيع المعتمد SHA256:** `6B8268E5B647B12A2AA055D7A22F7B8EA888E40FB863E74409938AAD4EC789C9`.

توجد نسخة APK موقّعة سابقة من 29 أكتوبر تحمل 1.8.1 والشهادة نفسها، لكن ملف `classes.dex` فيها يختلف عن البناء الحديث؛ **ليست نسخة آخر التطويرات**. لا تُسلِّمها باعتبارها الناتج الجديد.

## تجهيز التحديث الحقيقي

1. تحقق من نجاح الوظائف الثلاث في GitHub Actions على **أحدث Commit**، ثم نزّل الأثر `wen-1-8-1-original-package-unsigned`. داخله `Wen-Sarafet-1.8.1-aligned-UNSIGNED.apk`. لا تثبته على هاتفك، فهو غير موقّع.
2. استخدم جهاز صاحب **المفتاح الخاص الأصلي فقط**. ضعه في مجلد سري خارج GitHub والمستودع. الشهادة العامة لا تكفي لإعادة التوقيع.
3. جهز JDK 17 وAndroid SDK Build Tools 35.0.0 والمتغيرات البيئية التالية **محليًا** بدون تخزين كلمات المرور في ملفات المصدر:

   ```bash
   export ANDROID_SDK_ROOT="$HOME/Android/Sdk"
   export WEN_SARAFET_KEYSTORE="$HOME/private-signing/original.jks"
   export WEN_SARAFET_KEY_ALIAS="wen-sarafet-test"
   read -rsp "Keystore password: " WEN_SARAFET_STORE_PASSWORD
   printf '\n'
   export WEN_SARAFET_STORE_PASSWORD
   # إذا كان للمفتاح كلمة مرور أخرى: WEN_SARAFET_KEY_PASSWORD
   ```

4. من جذر المستودع شغّل سكربت التوقيع المحلي؛ الوسيط الثالث هو APK الأصلي الموقع من 1.8.0 إذا كان متاحًا:

   ```bash
   bash scripts/sign_verified_upgrade.sh \
     /path/to/Wen-Sarafet-1.8.1-aligned-UNSIGNED.apk \
     /path/to/Wen-Sarafet-1.8.1-SIGNED.apk \
     /path/to/original-1.8.0.apk
   ```

   السكربت يمنع توقيع APK قديم أو موقّع مسبقًا، ويراجع بصمة المفتاح الخاص، وpackageId، ورقم الإصدار، وتوقيع V2/V3، ويشغّل `scripts/verify_release_payload.py` لمطابقة جميع موارد وكود APK الموقّع مع البناء الحديث، ويرفض أي `classes.dex` قديم أو ملف متغيّر.

5. قبل تثبيت التطبيق الأساسي أنشئ نسخة احتياطية مشفرة واحفظ APK الأصلي. جرّب التحديث فوق 1.8.0 **دون حذف التطبيق أو مسح بياناته** على جهاز اختبار. تحقق من بقاء التفعيل، AndroidKeyStore، PIN والبصمة، أرصدة العملات، عدد العمليات، أرصدة الديون وسدادها، التحويلات، الرسوم، الإشعارات، Widgets ونسخة Drive المشفرة والاستعادة.
