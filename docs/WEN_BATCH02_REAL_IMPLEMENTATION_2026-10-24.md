# وين صرفت — تقرير دفعة تطوير محلية ثانية 2026-10-24

## الحالة الدقيقة
- مصدر النسخة الأساسية هو حزمة v1.8.0 المستعادة، وليس نسخة الكود الأصلية المؤكدة 100%.
- جميع تغييرات المصدر في هذه الدفعة موجودة في ZIP الحاضر. مستودع GitHub العام ما زال يحوي **محركات المصدر المستقلة** فقط؛ ولا يحتوي كامل مشروع Android حتى الآن.
- تم تشغيل اختبارات منطق Java والتحقق من صياغة 50 ملف Java وXML لعدد 38 ملفًا.
- لا يوجد Android SDK ولا Gradle في بيئة التنفيذ الحالية؛ لم يُبنَ APK، ولم نختبر التحديث فوق الإصدار المثبت.
- لم يتم المساس بملفات الحماية السبعة الموجودة في المصدر: AppIntegrity / AppLockManager / BackupCrypto / LicenseManager / LicenseProtocol / InstallationIdentity / SecurePinStore (مقارنة بايت ببايت مع Batch 01).

## تغيرات قابلة للتتبع
1. C1: محرك اقتراح التصنيف موجود أصلًا من Batch 01 ومرتبط بشاشة الإضافة. يعتمد الحساب والمبلغ والوصف والبيانات المؤكدة. يحتاج اختبار جهاز.
2. C2: تمت إضافة جدول change_history بنسخة DB 10، ومشغلات SQL لتوثيق إضافات وتعديلات وحذف المعاملات وأجزاء التقسيم وتغيير التصنيفات. شاشة داخل الإعدادات. التراجع متاح *فقط* لآخر تغيير تصنيف عادي مستوفٍ للشروط؛ تراجع الحذف والديون والتحويلات لم يُفعّل لأسباب سلامة محاسبية.
3. C3: MonthlySavingsRules + لوحة المتبقي أثناء الشهر والتهنئة بعد انتهاء شهر له سقف مسجل خاص بذلك الشهر. لا يوجد رصيد ادخار وهمي ولا حساب ادخار جديد.
4. C4: تنبيه التصنيف يقرأ العدد الفعلي وقت الإرسال ويلغي تنبيهًا قديمًا عند الصفر (محفوظ منذ Batch 01).
5. C5: حوار التحويل متعدد العملات بين أي حسابين بعملتين مختلفتين (مثل بنك USD وجوال باي ILS) من Batch 01؛ تمت إضافة زر تحديث أونلاين وزر حفظ صغير، مع جلب معدل الشراء الإرشادي للدولار/الشيكل من صفحة بنك فلسطين عند فتح الشاشة (ليس تحديثًا في الخلفية طوال اليوم). يمكن إدخال السعر يدويًا، والسعر المنشور لا يحل محل المكتوب دون موافقة. فشل الجلب يعود للوضع اليدوي. الموقع قد يغيّر HTML وبالتالي لا يُضمن نجاح الجلب حتى تجربة جهاز واتصال فعلي.
6. C6: تقسيم جزء إلى دين/سداد دين لم يُدمج في الدفعة، لتجنب كسر دفتر الديون دون اختبار Android شامل.
7. C7: إضافة بطاقات للدخل والحوالات المستلمة داخل شاشة التحليلات بالعملة والتاريخ، مستثنية الديون والتحويلات بين الحسابات. حاليا «مستلم» يعتمد تصنيف «حوالة مستلمة» الموجود وليس كل العمليات الداخلة.
8. C8: إزالة تصنيفات فردية أو متعددة من شاشة إعدادات؛ غير المستخدمة تحذف والمستخدمة تؤرشف مع حفظ التصنيف القديم لعملياتها، والتصنيف غير المؤثر في الميزانية المحمي لا يحذف.
9. C9: استخدام النظام لتقليل الحركة وتعديلات صغيرة للحركة، ولا تزال تجربة الأنيميشن الكاملة على الجهاز غير مختبرة.
10. C10: إضافة هوامش لأزرار التنقل وأيقونات عمودية لمنع التزاحم. لم تصل لقطة الشاشة المرجعية المطلوبة من المستخدم داخل هذه المحادثة بشكل يعرض موضع المشكلة الحقيقي.
11. C11: اختيار رموز التصنيفات من قائمة رموز حديثة في الإعدادات وتخزينها محليًا، مع الحفاظ على العلاقات القديمة. نظام تغيير كل أيقونات التطبيق لم يُنجز.
12. C12: إضافة Liquid Aurora وLiquid Fusion بعد 16 ثيم قديمًا دون تغيير مصفوفاتها أو ترتيبها.
