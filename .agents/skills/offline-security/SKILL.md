# offline-security

Audit actual manifests, SDKs, dependencies, network paths and data flows. Preserve databases, migration paths and financial semantics. Remove or block internet features only within explicit scope; validate offline launch, backups and permitted functionality. Never copy private medical data, finance records, tokens or signing materials to public services. Use least privilege; do not bypass platform protections. Flag unresolved privacy findings.
