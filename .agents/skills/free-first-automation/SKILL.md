# free-first-automation

Use existing free tools and public standard GitHub runners within terms; check actual quotas and storage first. Prefer scripts and existing test runners before model calls. Do not enable paid services, add billing, disclose secrets, or bypass limits. Cap retries and timeouts, checkpoint idempotently and preserve evidence; stop on missing permission or quota. Use model/API only when available at no additional cost and suitable. Report recurring cost assumptions, failures and user actions genuinely required.
