# android-visual-qa

Extract measurable design tokens, geometry, typography, states, RTL/LTR and reference viewport. Implement native or actual project stack; never substitute generated mockups for runtime screenshots. Test portrait/landscape phone/tablet, compare actual shots with approved references, check clipping, overlap, contrast and interactions. Prefer existing emulator and CI before adding tools. Record reference versus actual dimensions and differences. No invented screenshot or hardware result.
