# project-continuity

Read current project-specific AGENTS, plan, handoff, active PRs and latest branch/CI. Distinguish user requirements from historical notes. Check overlapping work and choose a non-conflicting scope. Do not redo existing changes or discard newer branches. Planning alone authorizes no writes. Record exact base/head, files, tests and remaining blockers; preserve existing local rules. No claim without evidence.
