# graphics-performance

Measure existing baseline before changes. Preserve engine ownership and product functions. Use deterministic gestures and tests for cancel/commit, RTL/LTR and orientation. Profile actual frame timing with existing tooling; 120 Hz implies 8.33 ms theoretical interval, not proof of performance. Avoid expensive allocations, synchronous snapshots and redundant layers; compare alternatives on measured evidence. Separate browser, emulator and physical device results. Never claim a physical refresh rate from software rendering.
